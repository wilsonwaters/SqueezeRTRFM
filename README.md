# SqueezeRTRFM

A [Lyrion Music Server](https://lyrion.org/) (formerly Logitech Media Server) plugin for
[RTRFM 92.1](https://rtrfm.com.au/), Perth's independent community radio station. It adds
"RTRFM 92.1" to the Radio menu so you can play the live stream; on-demand episodes and track
listings are on the way. This is an unofficial plugin and is not affiliated with RTRFM.

**Work in progress** — installation instructions will follow with the first release.
